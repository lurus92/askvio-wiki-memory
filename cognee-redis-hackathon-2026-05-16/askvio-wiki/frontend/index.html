How Cognee is used here:
Raw HTML lands in Redis first via cognee.remember(..., session_id=) — the fast, ephemeral scratchpad.
GPT then distils each page into structured wiki entries, which are stored in Cognee's permanent knowledge graph via cognee.remember(entry).
At query time, cognee.search(SearchType.GRAPH_COMPLETION) traverses the graph (wiki) while cognee.search(SearchType.CHUNKS) does raw cosine similarity (vector baseline).
Low ratings trigger a SkillRunEntry — Cognee proposes a rewrite of the query/SKILL.md, which you apply with the button above.
